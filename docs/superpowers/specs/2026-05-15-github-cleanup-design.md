## Files to Add

### `.gitignore`
Ignore OS files, editor files, and Node.js artifacts:
- `.DS_Store`, `Thumbs.db`
- `.vscode/`, `.idea/`
- `node_modules/`, `*.log`
- `vi-translation-cache.json` (generated by the translation script)

### `README.md`
Contents:
- App name (Blebleble) + one-line description: "A Vietnamese-English vocabulary learning web app"
- Live demo link (GitHub Pages URL)
- Features list: Dictionary, Flashcards, Quiz, New Words Quiz, Grammar & Sentences
- How to use: open `index.html` in a browser, or visit the GitHub Pages URL
- Tech stack: vanilla HTML/CSS/JS, no dependencies, no build step

## App Change: Remove Numbers Mode

In `index.html`, remove the "Numbers" study mode card (labeled "Learn and practice Korean number systems") from the Study tab, along with any associated JavaScript logic for that mode. All other study modes remain untouched.

## GitHub Pages Deployment

No extra config file needed. GitHub Pages serves `index.html` at the repo root automatically.

**Steps after pushing:**
1. Go to repo Settings → Pages
2. Set source to `main` branch, root folder
3. Save — GitHub Pages URL will appear within ~1 minute
